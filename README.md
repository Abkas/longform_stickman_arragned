# longform_stickman_arragned

Orchestrator workspace for the `long-form-stickman-yt` channel's production
pipeline — Claude Code skills (`topic-scout`, `title-writer`, `script-writer`)
and agents (`shot-list-builder`, `visual-generator`) that turn the channel's
locked format/tone/visual rules (see `../long-form-stickman-yt/assets/brain/`)
into an actual delegated workflow instead of ad-hoc re-application each
session.

Run Claude Code from *this* folder to work on a video — see `CLAUDE.md` for
the full pipeline map and how each stage is handled. This folder holds no
production content of its own; the real project (videos, brain files,
pipeline code) lives in the sibling `../long-form-stickman-yt/`.
